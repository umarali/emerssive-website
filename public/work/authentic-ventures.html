What I did

01New hosting, under Authentic Ventures' control

Set up a new cloud server on Cloudways, moved the site onto it, and created a staging copy at staging.authentic-ventures.com with its own SSL certificate. Every change was reviewed there before the public launch, and the site now lives on hosting the firm controls rather than the build agency's.

02Safe migration

Moved the full database and all files, then rewrote every internal address using the method WordPress requires, since a crude find-and-replace corrupts content silently. One deployment step broke the server configuration mid-migration. I recovered it the same day, at no charge, and hardened the setup to prevent a repeat.

03Code in version control, with controlled deployments

Placed the full site code in a private GitHub repository with secrets and credentials excluded, and connected it to the server so future changes can deploy from version control in a tracked, reversible way instead of by hand.

04Pre-launch audit: what it caught

  • The contact form was silently failing. Submissions were saved in the database but the notification emails never went out, so enquiries were being lost with no error shown to anyone.
  • The staging site was fully open to Google, which risked duplicate-content damage against the live site.
  • The homepage had no search description, and links shared on LinkedIn or Slack showed placeholder text with no image.
  • The domain had no email security records (SPF, DMARC), so anyone could send email pretending to be @authentic-ventures.com.
  • Cloudflare's security settings were blocking Google's crawler and LinkedIn's link preview tool.

05Contact form rebuilt and verified

Notifications now send through an authenticated Google account, so they reliably reach the inbox. Added a branded email template with the Authentic Ventures logo, a check that rejects email addresses whose domain cannot receive mail, and the missing SPF and DMARC records. Verified end to end with real submissions on both staging and the live site.

06Search and social presence fixed

Wrote a proper search description for the homepage, replaced the placeholder share text, added a real share image, and set every page title to the clean, consistent style Authentic Ventures chose. Links shared on platforms like LinkedIn and Slack now show the firm's brand instead of sample content.

07The launch

Executed after business hours on July 22: fresh backups first, then the domain pointed at the new Cloudways server through Cloudflare, the production SSL certificate issued, search indexing opened, and the Cloudflare settings that blocked crawlers and link previews fixed. The plan was rehearsed on a replica, the old site stayed running as a ready fallback, and downtime was a few minutes. Before confirming it live I verified every page, every redirect, and a real form submission delivered end to end.

08Handover, access and security cleanup

Removed the agency's footer credit link and leftover development files, closed their remaining administrator access in favor of a scoped editor login for their SEO review, issued fresh credentials for the Authentic Ventures team, and pointed the site's admin email at info@authentic-ventures.com. Only the firm and I hold administrator access now.

09Post-launch wrap-up: in progress

Part of the fixed price, confirmed as each item completes: monitoring and rechecking the live site through the days after launch, Google Search Console registration and sitemap submission, search descriptions for the remaining inner pages, switching the form sender to info@authentic-ventures.com once the Google Workspace steps are complete, shutting down the previous hosting so its billing stops, and arranging retirement of the agency's development copy so nothing competes with the live site in search.
